# 毛球大冒险 · 实体麻将与海岛焕新

默认入口为 scenes/party/adventure.tscn，Godot 4.7.2。支持两名本地玩家或一人＋真实AI，没有棋盘网络联机或存档。

## 开始旅程

独立包完整解压后双击 Play.cmd，选择伙伴模式，再开始完整三章旅程。章节卡可单独试玩，明确不计前章通关。Edit.cmd 打开随包可编辑源码；修改源码后需要重新导出PCK才会改变运行包。

三章各54格，有分岔、高架和收费交通。普通落点处理后轮到伙伴，不再每两人行动后强制战斗。经过挑战站/出口会停靠并放弃剩余步数，玩家可进入或离开。每章取得两处不同挑战印章后走到出口；失败可原站重试，难度不因重试次数增加。

金币、星铃、长期构筑跨章保留，章节资源随章变化。道具店售加骰/保钱/互换位置；摊位提供营业收入与本区道具折扣。海岛地产影响战斗属性；后两章地产在本区各新挑战首次开启时供应对应资源，重试不重复发放。

## 三种玩法

1. 海岛远征：合作自动攻击割草。挥锅与锅能、站定蓄能与迈步齐射、诱饵聚怪与连爆，三种流派有不同技能。首次实际胜利的免费工坊就提供本职业两种核心打法与一件基础改装，第二场可以体验成型机制；可花6金追加基础改装。经验、装备和等级持续积累，各地区任务不同。
2. 云顶雀馆：真实立体麻将桌，136张实体牌、万筒索及风箭牌各4张。每人13张、摸牌后14张，打牌、吃碰、明杠暗杠加杠、补牌、自摸、荣和及抢杠均用实际库存；标准四组一对或门清七对可胡（四同牌计两对）。鼠标点击本方牌，再按“打出选中牌”确认。对方暗牌在AI模式隐藏，同机双人按当前操作者转桌。两人共同挑战，一人胡牌全队得挑战印章。可选公开残局（有清楚标记的近完成起手）或真正随机洗136张的自由牌局；最多64次打牌，流局不给印章。流派工坊每人单槽门清/刻派/连序，分别解锁一次真实窥墙排取、碰杠后换本次摸牌、吃牌后窥墙；达成本场指定牌型可获额外实际金币。棋盘资源券可窥牌或交换本次摸牌，不是万能牌。
3. 时光空港：两人每拍各走一步，八拍一轮，最多三轮。录下走到双踏板的真实路线，在双方站板时封存；下一轮让旧回声供电，当前动物去同色交付点送达。旋转券改变旧轨迹，余辉券延长离板供电。时间表只显示旧轨迹，真人贡献单列。三处机关路径不同，新挑战重新录制。

## 操作

棋盘Space掷骰，数字键或点击选择。Tab总览/跟随，Home回动物，滚轮缩放，右键拖动；F1手册，F10声音，F11全屏。

海岛战斗：P1 WASD/Space/Q，P2方向键/Enter/斜杠，分别为移动、冲刺、技能。自动攻击，靠近倒地伙伴救援。普通时间结束可完成，仍有Boss时须击败；全队倒地失败。

麻将：鼠标点实体手牌选择，按钮确认打牌；数字键对应当前可见动作。需要声明吃碰杠胡时按实际可选动作，窥墙后选择三张真实牌的取牌顺序。回声：数字键或卡片选择。资源按钮仅在库存和使用条件均满足时可用。失败重试和退出由伙伴共同确认，AI继续负责实际走棋与活动动作。

海岛新增配送/勘探委托：在04/18/32站支付押金，至少真实移动4步后到目标落地兑现；勘探还需亲自经过工坊。期限按两名玩家轮换计手，可花1金币支援伙伴延长2手，并亲自配送分得2金。每人每章每站每种限接一次；逾期及跨章离开不返押金。选择绕路、渡船、停靠或保留现金有实际代价；进入挑战站仍由玩家决定。

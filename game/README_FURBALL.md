# 毛球暴走 · 夜市合作生存样板

## 启动与操作

用 Godot 4.7.2 打开本目录的 `project.godot`，运行默认 `scenes/furball/main.tscn`。独立运行包的 `Play.cmd` 使用随包引擎和已编译 `furball.pck`，首次启动无需导入源码或配置 Blender。`Edit.cmd` 用于打开 `project` 内源码；源码编辑后需重新导出 PCK 才能更新运行包。

- P1：WASD 移动，空格冲刺，Q 技能；武器自动攻击。
- 本地 P2：方向键移动，Enter 冲刺，/ 技能。
- 成长与棋盘：鼠标或数字 1/2/3，按面板提示选择；本地双人依次选择成长，每轮轮换操骰者。
- 首轮掷骰前用订单下拉框选连单，空格或按钮掷骰同时承诺订单。1倒车按骰点花2券、2原步数免费、3正向加一步花1券。本地等待方用 Shift+1/2/3 提议对应路线；联网等待方用 1/2/3 提议。建议不消耗券，最后由操骰者决定。
- F1 查看营业规则，F8 精简表现，F9 主静音，F11 窗口/全屏，Esc 返回营地并结束本局。
- 营地可独立开关夜市旋律，表现、主静音、旋律选择会保存。

营地种子留空随机，或输入 1～2147483647 的整数重试结算种子。战斗、成长与路线使用独立随机序列；相同种子、流派及成长选择会复现候选，实际走位与路线仍会改变结果。

## 夜市与成长

承诺长出了腿，毛球要从收账员手里取回关门铃。六站常规敌潮各约 35 秒；第三、六站 Boss 未倒下时继续战斗，倒计时结束停止新增杂兵。

第三站 Boss 使用近身收账；第六站经理交替近身收账与紫色加班通知。通知固定在旧落点，完整圈显示危险范围。击败经理取消尚未落下的通知。

三种流派：

1. 甩锅：近战挂锅印；接伤积蓄锅能，Q 范围爆发；附近搭档获得减伤。单人锅印击败也能回收锅能。
2. 摸鱼：自动射击，站定蓄能，重新移动释放强化齐射；Q 装满蓄能后仍需移动。
3. 画饼：投放诱饵吸引追兵，延时爆炸；Q 投放更快爆炸的诱饵，锅印提高兑现效果。

关门改造成型后会改变动作：甩锅「判词」积蓄至少35锅能后，Q 沿移动方向放出向前推进的白金锅浪；摸鱼「流水线」满蓄迈步时锁定前方120°扇区，初轮仍打最近敌，两次追加各接档13米内不同活目标，优先正在蓄势的冲锋/远程敌。转身不会改变本次已锁方向；没有新目标就沿初轮方向追加，不主动转向Boss。追加数量、伤害与延迟保持原值。可以向另一群迈步给接货路线开路；「静音狙击」仍同线追加一轮穿透，适合排队敌群。画饼「连兑」按距离排序引爆最多6个自己的诱饵，路径箭头与编号显示尚未兑现的顺序。HUD 分别记录每位玩家实际锅浪、追加齐射、参与连兑的饼数。

成型后的锅浪、追加齐射和参与连兑的爆炸，在真正命中冲锋或远程敌人的蓄势时会打断招式，造成0.45秒硬直，再进入短恢复；可以为搭档接货、充奶站或搬箱争取窗口。普通攻击、初次齐射、未参与连兑的诱饵和 Boss 不受这条规则影响，已经发出的敌弹也不会消失。每名敌人有2.5秒打断间隔，同一帧最多打断8招，反馈合并显示。

成长包括武器（3～6）、火力、移速、范围、暴击、协同、治疗与弹射，每张卡展示实际作用和代价。招牌改装每流派最多两次；第三站结束有两个互斥的关门改造分支，也可选择普通改装。两个封条随第三、六站完成解除，实际夜市道具与铃声同步反馈；重新开局恢复。

## 十二格骰子棋盘与经营

队伍共用一辆摊车、钱袋和三街区执照。六轮从60金、2张步数券出发，双人轮换操骰。掷1～6点后可倒车按原骰点走（2券）、正向原步数（免费）或正向加一步（1券）；旧减一步已替换。落点决定下一站的街区，预览同时展示该站实际布局。正向经过起点获得12金；倒车经过不领绕圈补助，两方向落起点仍加4金，落关门奖池仍加10金。步数券最多3张，事件和补给按余下每骰最多2券计算实际用途；末轮及券已到用途上限时不再发券或扣购买费用，已有券保留。倒车花两券可能补到前方三路线没有的缺货街区，也会牺牲旧减一步选择和后续控路资源，并非总是更好；骰6的两向落点相同，免费正向尤其值得比较。

外部巡街车还会威胁相邻两格，棋盘红框和选路按钮会显示最终落点是否使本战刷新增加25%；仅经过不受压。它与事件追缴的25%取较大值，挑战再加50%，合计最多1.75倍，敌人血量不变。完成当前街区完整委托后，巡街车下轮前进1格；未完成前进2格。完成不会降低已经开始的本场压力，也不额外发钱。骰路、订单取货和步数券因此会受上一站委托结果影响。

落在事件格先选择事件，再保留一次经营机会：

- 机会扭蛋：现在收6金，或领下一轮路线券；钱袋或券满时不提供无收益报价。
- 巡街收账：付8金，或保留现金承担下一战1.25倍刷新；再接经营挑战时合计1.75倍刷新，不增加敌人生命值。
- 合作驿站：领路线券，或按每位存活搭档的开场余量援助锅能10、蓄能0.5或诱饵1。

经营可投资、挑战、留钱或购买补给，每轮只能选择一种。当前街区执照购买22金、升级18金，异地加6金；每区最多二级。执照给予开场补给，二级在完成本地目标时触发短时强化。挑战提高刷新并改变收益，留钱立即开战。补给有12金奶（购买时恢复存活缺血者20生命）、10金资源包、14金路线券；资源包先计入地产和免费事件，再按实际余量报价，进入战斗后一次兑现。资源满或末轮无用途的券不可购买；升级地产可能挤占先选的免费援助，面板会提示。

抢档挑战采用 v2 委托开档：本场第一次真实账台、奶站或接包进度登记抢档，最迟开战11秒自动登记。至少预告0.75秒，再标记下一批既有压力群的2–5名敌人；没有额外刷怪，Boss不标记。从这群实际生成起8秒内全清，加上完整街区委托与正常站胜，才兑现额外8金。挑战未达成仍保持本场压力；正常站胜保留基础收入，全倒没有闭站收入，已有钱袋不倒扣。早做委托或先移动蓄能会影响遇到哪一群，需要自己取舍。

旧 v1 抢档回执仅按原版本只读评价，不会转换成 v2，也不能领取当前新局奖金。GM准备与自动评价均不能证明真人已认可玩法或所有晚波公平。

三街区各有三套真实布局，账台/墙体、物流方向和奶站/合流点随回合变化：

- 串串巷：绕摊换道，在任意两个账台停留完成营业。
- 物流街：看横、纵或交叉路线的预告，横穿接住三件包裹，避开运输车。
- 夜奶广场：充满两座奶站，再到合流点开席；双人可分工，最后合流更快。

物流车流还可能把下一群追兵引到该条实际线路两端，蓝色双圈表示候选入口。截货者可以迎货、提前横移，搭档则可守入口或用成型打断开路。每次真实包裹预告最多影响下一次既有刷新，人数、刷新时刻、敌血及奖励不增加；预告不足0.35秒、超过1.8秒、喘息期单个敌人或两端不安全时照原入口进场。实际生成前整群检查，离每名角色（包括倒地者）至少5米，不会部分挪入。交叉地图也包含一条横线，斜线入口由实际斜线包裹触发。蓝圈消费、到期、换场或等待房主更新后消失，不保证其中一端必定来敌。

首轮还有两张合伙连单可选，各需两个不同街区的货。完成对应街区的完整委托才取到货，重复街区不会多取。路线预览会说明本街是缺货、已有货还是无需取货；等待方可用路线旗表达意图，每轮首次加最多两次修改，修改间隔至少0.75秒。

两货齐后生成一个紫封配送箱，靠近后按 E 选直送、R 选外圈并发货，本地 P2 对应逗号、句号；战斗继续。地图预览两条线路的入口，HUD 显示几何路程。外圈先去边缘接力点，路程至少比直送长2米，再到共同终点；边缘也可能刷怪，不保证安全。先后经过编号1、2才能交付，路线在本场锁定，奖励相同。

冲刺、实际受伤或倒地会放下箱子；按 E 拾回原线路（本地 P2 用逗号），R 不能重选。刚放箱的演员一秒内不能重取，搭档可主动接力。箱子没送完可保留已取货、下一站重新选线配送。第5站及之前交付，结束该站后先正常改装，再让每人各选一次订单额外改装；第6站交付仅履约。共同六站胜负保留，结算另记连单履约结果。

每站目标只兑现一次，F1 显示账台/包裹/奶站与合流进度。结算保留种子、实际街区、委托、投资、挑战、改装和合作贡献，并提供逛遍三街区、兑现三次挑战、六站委托全完成的下一局目标。共同胜负仍是撑过六站并击败经理；这是合作经营棋盘，目前没有个人钱包、互害或独立棋子对抗。

## 合作与直接地址联机

本地支持甩锅＋摸鱼、甩锅＋画饼。联网房主选择组合并创建，队友输入房主地址加入，UDP 27842；同机双进程使用 127.0.0.1。联网双方各用 WASD、空格、Q 控制自己的毛球。

房主计算战斗，客机提交输入和改装选择，双方按站轮换领路权。倒地后搭档在约 2.2 米内保持 2.5 秒可救起。金线与搭档金圈显示实际护盾覆盖；结算的搭档减伤与自身减伤分别统计，救援计给帮助者。

存活搭档撑过一站后，全队恢复 12 生命，倒地者也会起身再选改装；两人都倒下则本局失败。客机超过 0.75 秒未收到新快照，会显示等待更新提示，恢复同步后自动消失。房主超过 0.6 秒未收到客机输入时停止沿用旧移动方向，收到新输入后恢复；等待期间战斗仍继续。

已有同机两个真实引擎进程的完整战斗、成长、路线、最终经理、结算与断线返回验证。当前不提供公网匹配、中继或断线重连；跨设备网络及真人合作感受仍待实测。

本机 UDP 中转测试还覆盖随机延迟、3% 丢包、重复包、乱序和 1 秒断流；两端自然通关并核对最终状态。该诊断不能代表真实跨设备 Wi-Fi 或公网体验。

随后加入远端输入失效修复的完整故障网络对局自然在第六站失败，双方状态仍一致；胜负均原样保留。真实 2 秒断流另行验证等待提示、远端停止移动与输入恢复。最新同一对进程连续两局真实 UDP 验收分别用甩锅＋画饼、甩锅＋摸鱼和不同种子自然通关，返回营地、再次建房/加入后模型、成长、关门铃与连接状态正确重置。

## 表现与资源

游戏使用原有轻量 GLB 柯基与点心夜市，增加画饼小帽、移动/冲刺/蓄能/受击/庆祝的有限整体动作反馈，尚无骨骼蒙皮。高品质真实毛发 Blender 柯基单独交付，没有直接替换游戏角色。

`tools/.gdignore` 隔离原工程的工具运行库，`project.godot` 关闭直接 Blender 导入。独立运行包不包含原工程整套 Blender 工具；游戏加载 `assets/furball` 的资源。

原版 Noto Sans CJK SC 字体随项目提供，版权、OFL 1.1 和来源说明位于 `assets/furball/fonts`。`visual_style.gd` 对新导入和编译包统一关闭系统字体回退。原创夜市旋律与有限并发提示音保存在 `assets/furball`。

## 结构、预算与验证

权威规则在 `combat_model.gd`，成长在 `build_catalog.gd`，棋盘/事件/补给分别在 `board_runtime.gd`、`board_events.gd`、`team_supplies.gd`，路线旗在 `route_suggestion.gd`，连单与严格状态检查在 `shared_order.gd`、`shared_order_validator.gd`，有界配送几何在 `shared_order_paths.gd`，街区布局与目标在 `district_catalog.gd`、`district_runtime.gd`，敌潮节奏在 `encounter_director.gd`，经理模式在 `boss_catalog.gd`。`entity_pool.gd` 固定槽位并保留稳定身份，`spatial_grid.gd` 查询邻域；表现模块消费实际模型状态，`furball_session.gd` 组织输入和界面，`market_story.gd` 负责关门铃。`route_catalog.gd` 的旧两路规则仅保留给显式诊断模式。

敌人256、玩家弹丸192、拾取物192、诱饵12；自然敌潮上限80，冲锋/远程特殊敌人合计最多24、敌弹最多36。普通反馈事件96、跳字24（其中6个保留给重要信息）、动作弧12、碎屑48；关键危险与合作信息使用独立预算，精简表现仍保留。连兑路径/端点/编号固定12组，锅浪最多4条。

联机快照约 12 次/秒、输入约 20 次/秒，压缩后分成 1000 字节块；发送与接收都限制原始128KiB、压缩32KiB、最多32片和3份组装缓存，过期/缺块快照丢弃。非法连单、棋盘或成长版本会拒绝整帧。客户端按稳定身份做有界表现插值，伤害与死亡仍来自房主，不是完整预测或回滚系统。

规则检查：

```powershell
& tests/run_current_quick_checks.ps1
```

当前默认执行委托v2、双向骰路、付费/免费券、危车纯域与真实GM/Model的8项快速脚本；范围及历史fixture见 `tests/README.md`。旧两个检查入口默认转到这组，`-Historical` 仅用于相应旧源码。脚本会选择原工程 `tools/godot` 或独立包 `runtime` 引擎，也可用 `-Godot` 显式指定路径。导入和各项原生规则检查都会扫描错误日志、退出码和成功标记。该命令不执行真实双进程联网、实机录像或人工上限性能场景；这些证据另行记录。

实际正常对局、两进程网络与注入上限场景分别保留范围和源文件哈希。录制的 12fps 是视频采样节奏，性能来自独立原生测量。当前没有真人试玩或主观听音结果，自动诊断的胜负不能证明普遍难度或乐趣。

本轮迭代使用功能、单元与结构快验，不执行长时间测试。旧自然对局和长期性能记录对应旧版源码；新版棋盘、事件、补给与build动作有各自受控快验和短实景记录，不能把旧证明直接当作新版整局验收。

## 开发调试

用引擎启动项目时在引擎参数之后加 `-- --furball-dev`，按 F10 打开 GM 控制台，输入 `help` 或 `board help` 查看固定指令。支持 `build 1 core`、`pot 1 50`、`charge 2 2.5`、`bait 1 3`、`spawn 3 4` 等受限准备。GM 默认关闭，只允许单人、本地或房主执行；干预会标记本局为调试记录，不能算普通局目标达成。控制台打开时隔离移动和技能输入，Esc 先关闭控制台。

`board order 0` 或 `board order 1` 可在首骰前承诺一次连单，`board roll 1` 指定骰点并保留已选订单；后续走格和经营仍遵循正式阶段与演员权限。GM 不直接注入货物或订单奖励，取货与交付需经过正式街区和配送规则。

物流借车掀阵：按真实车道引普通敌群入线，再侧闪接后方包裹。每辆行驶危车最多掀开8只普通敌，沿车道两侧推开2.4米；Boss、冲锋和远程敌免疫。它不造成伤害、打断、击杀或金币，玩家原有8点危车伤害仍在；接走包裹就移除该车。双人可分工引潮与截货，推开的抢档标记群也可能更难及时清完。黄色预告和F1目标提示沿用现有规则，青色“借车掀开”显示实际位移人数；不新增角色或声音。

# 百番夜宴 · 借形连响

Godot 4.7.2 项目，包含完整三章冒险和独立的 3D 麻将肉鸽玩法。

## 开始试玩

1. 用 Godot 4.7.2 打开 `game/project.godot`，等待首次资源导入。
2. 运行 `game/scenes/party/mahjong_night.tscn` 进入百番夜宴；主场景保留三章冒险入口。
3. 建议先选“先练一手 → 赤封回环”，可关闭指引自由尝试。同一起手有 316 与 346 两种已验证路线。

## 本轮核心玩法

花有限灵感，将自己已亮出的三张明组与手牌交换 1—2 张，重组成合法顺子或刻子；借回的真实牌可在本回合追击第二组。也可选择直接续奏，或用公开河牌补形。旧组不会重复给分，136 张实体牌保持守恒。

包含三路线构筑、押约、挂件、商店、真实 AI 与本地双人，3D 拆换与第二组三牌展演，以及原创连响音效。练习最好分只保留在当前会话。

## 仓库内容

- `game/`：可编辑 Godot 项目、运行所需模型、材质、UI 与音频。
- `models/`：继承的 8 份 Blender 编辑源和模型清单。
- 根目录 `build_*.py`、`make_*_audio.py`、`bake_*.gd`：模型与声音配方。
- `source-freeze.json`：已交付的 1239 个生产源码文件校验清单。
- `制作与验证说明.txt`、`模型与音效编辑说明.txt`：制作、验证与来源说明。

## 验证与当前限制

最终试玩包通过普通随机/真实 AI/本地双人/射线交互，以及练习同手两解验证。商业美术、完整自然三桌平衡与部分性能预算尚未达标；无线上联机、战役存档或永久成长。社区角色商业分发许可尚未证实，资产来源见 `game/ASSET-SOURCES*.txt`。

本仓库排除 Godot 导入缓存、测试录像、运行日志、平台运行时与打包成品，保留原始游戏资源和历史兼容入口。

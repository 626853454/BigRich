# BigRich · 百番夜宴

Godot 4.7.2 的 3D 麻将构筑游戏，保留三章冒险入口。本轮把第一组牌、短关成长和成型爆响连接起来。

## 开始玩

1. 用 Godot 4.7.2 打开 `game/project.godot`，等待首次资源导入。
2. 运行 `game/scenes/party/mahjong_night.tscn`。
3. 建议先“第一次玩”，再玩“午后小桌”；已有经验可直接“完整夜宴”。

教学用同一套真实计分展示 52 → 99 → 三组 529。三小关每关只做两三次组牌，没有倒计时；自己选择风铃或茶炉核心、再选搭配。通关后同牌换序或换搭配，对比实际总分和单组峰值。预设小关与普通随机牌局明确分开。

茶炉火签实际 364 + 364 = 728，拆成两段实体牌动作、筹码、原创音效与 UI 反馈；风铃让同三张牌在桌前齐奏。空格只跳演出，不重复付款。

普通局仍支持随机 136 张真实牌、AI 或本地双人、公共河牌、借形/续奏、夜市和三桌成长。准备选项按需展开；主动求助只用自己的手牌和公开河牌。商店解释搭配条件与替换损失，再由玩家确认。

## 编辑与来源

- `game/`：Godot 源码、实时模型/材质、UI、音频。
- `models/`：继承的 8 份 Blender 编辑源，本轮没有新增角色模型。
- 根目录生成脚本与配方：包含新增 3 个原创构筑短音的 `make_welcome_build_audio.py`。
- `source-freeze.json`：本轮打包时更新的生产源码清单。
- `百番夜宴_先读这个.txt`、`制作与验证说明.txt`：玩法、验证范围和限制。
